# Real Assets Dashboard

Fund-grade local dashboard for a real-assets fund: gold, silver, platinum, palladium, copper and bitcoin. It covers:
- portfolio accounting and investor reporting;
- markets and futures term structure;
- a quant lab (spreads, butterflies, seasonality, relative value) with out-of-sample validation;
- macro and AI analyst briefs;
- validated ML direction models;
- a market-data center.

- **Install and operate:** see [docs/SETUP.md](docs/SETUP.md).
- **Start:** double-click `Start Real Assets Dashboard.cmd` (or `npm start`), then open http://localhost:3100.
- **Developers:** see [CLAUDE.md](CLAUDE.md) for architecture and commands (`npm run dev`, `npm test`, `npm run e2e`).
